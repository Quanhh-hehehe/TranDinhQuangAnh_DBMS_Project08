# 🎬 Cinema Management System (CMS)

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)

An enterprise-grade, CLI-based Movie and Cinema Room Management System built with Python and MySQL. This system features robust relational database architecture, dynamic spatial-temporal scheduling, ACID-compliant concurrent ticket booking, and Role-Based Access Control (RBAC).

## 1. Prerequisites
Before running this project on a new machine, ensure you have the following installed:
* **Python 3.10+**: Make sure Python and `pip` are added to your system's PATH.
* **MySQL Server 8.0+**: Running locally or via a remote host.
* **Git**: To clone the repository.

If you are cloning this project to a new machine, follow these precise steps to set up the environment:
